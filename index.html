Projects

VERIMED

VERIMED is an auditing pipeline for natural-language software requirements. Before a requirement becomes a formal model or an implementation, VERIMED checks it for ambiguity, inconsistency, vacuousness, redundancy, and safety violations — producing solver-based evidence rather than subjective review. Software engineers get concrete counterexamples showing where a requirement can be read in more than one way. Verification engineers get SMT diagnostics including unsat cores, violating assignments, and redundancy flags. Safety reviewers get a global consistency check across the full requirement set.

CloudFix

CloudFix is an LLM-assisted repair workflow for AWS IAM access-control policies. When a policy fails to satisfy its intended access specification, CloudFix uses SMT-based fault localization to identify the specific statement causing the violation, generates a targeted repair with an LLM, and verifies the patch formally before accepting it. The goal is to make policy validation, maintenance, and correction tractable at scale — replacing manual debugging with a structured, auditable repair loop.

AWS IAM Policy repair Fault localization Quacky + Z3
Evaluated on 282 real-world AWS IAM policies 84.0% repair rate vs. 48.2% baseline — a 36-point improvement on 10-request tasks 54.3% vs. 22.3% baseline on harder 30-request tasks — more than double the baseline

POLICYSUMMARIZER

Cloud access-control policies are reliability-critical artifacts, yet LLMs cannot reason about them with the precision security requires — a gap that persists even when the specification is the LLM's own explanation of the target policy. This work formalizes that finding as the Verifiable Synthesis Paradox and addresses it with POLICYSUMMARIZER: a neurosymbolic tool that encodes a policy into a finite-state automaton, extracts a regular expression characterizing all allowed requests, and uses an LLM to simplify it into a readable form. Model counting verifies the output before accepting it, falling back to the formally-derived expression if fidelity drops below a configurable threshold. In a user study, POLICYSUMMARIZER raised policy-change-review accuracy from 39% to 93% on the hardest sub-task, with 88% of participants preferring it over reading raw JSON.

Non-reasoning LLMs top out at 45.8% semantic equivalence, highlighting deployment reliability limits Reasoning LLMs reach 86.4%–93.7% — highlighting the gap between model classes Formal summarizer achieves 0.889 mean similarity on semantic request descriptions
