Projects

VERIMED

A neurosymbolic auditing pipeline for medical-device software requirements. VERIMED translates natural-language requirements into a unified SMT model, checks consistency, vacuousness, violatability, redundancy, and uses repeated formalization to expose ambiguity in the original text.

Natural-language requirements SMT Z3 Counterexample-guided repair
64/64 hemodialysis requirements formalized 55.4% to 98.5% verified QA accuracy with SMT counterexamples 12/64 ambiguity-sensitive requirements reduced to 0/64
Core formalization
ρi(x) ≡ pi(x) ⇒ qi(x),   M = C ∧ ρ1 ∧ ... ∧ ρn
Ambiguity check: C ∧ (ρa ∧ ¬ρb) and C ∧ (ρb ∧ ¬ρa) must both be UNSAT.

CloudFix

An automated repair framework for AWS IAM policies that combines formal-methods fault localization with LLM-generated candidate repairs. CloudFix maps failed requests to responsible policy statements, prompts the model with those failure causes, and validates each candidate repair with SMT-based policy analysis.

AWS IAM Policy repair Fault localization Quacky + Z3
282 real-world AWS IAM policies 84.0% full repair rate on 10-request tasks vs. 48.2% baseline 54.3% complete repairs on 30-request tasks vs. 22.3% baseline
Repair objective
Accuracy = Rc / Rtotal × 100%
ValidateGoal(P, R): every must-allow request satisfies P and every must-deny request does not satisfy P.

Access-Control Policy Synthesis and Summarization

A study of how well LLMs synthesize, explain, and summarize cloud access-control policies. The project shows that syntactically plausible policy generation can still fail semantic equivalence, then introduces an automata-based request summarizer that turns policy behavior into interpretable regular expressions verified with model counting.

Policy synthesis Semantic equivalence Automata Model counting
15.4% to 45.8% semantic equivalence for non-reasoning LLMs 86.4% to 93.7% semantic equivalence for reasoning LLMs 0.889 mean similarity for semantic request summaries
Policy semantics
Allow(P) = {(δ, a, r, e) : ∃ρi ∈ P, ρi = Allow ∧ ¬∃ρj ∈ P, ρj = Deny}
J(RDFA, RLLM) = Count(Aintersection) / Count(Aunion)
